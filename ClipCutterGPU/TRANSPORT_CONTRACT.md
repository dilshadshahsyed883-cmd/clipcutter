# Private GPU transport v2 — source implementation

All /api endpoints require the independent >=32-character Bearer token; Salad gateway authentication is separate. Public health endpoints disclose only startup status. VPS is authoritative; no Drive credentials on worker.

- GET /api/capabilities: readiness, dispatch_enabled, chunk_bytes (8 MiB), active_renders, staging, undelivered, concurrency (1 until measured parallel-2 acceptance).
- POST /api/jobs/{attempt_id}: create staging using {action,job,files}; job is existing Staged manifest; files maps source.video, required reference-01.img etc and approved-review.json for reference export to {size,sha256}. Attempt ID is 32 lowercase hex, distinct from logical job_id. Identical create is idempotent; changed manifest returns conflict. No ZIP/path extraction.
- PUT /api/jobs/{attempt_id}/input/{filename}?offset=N: raw <=8 MiB, Content-Length and X-Chunk-SHA256. Sequential append, identical replay accepted, conflict rejected. Return current offset; poll GET /api/jobs/{attempt_id} for offsets.
- POST /api/jobs/{attempt_id}/start reserves the one slot and checks sizes, then hashes all inputs before executing isolated subprocess. Status gives real progress/errors. POST /cancel cooperatively cancels and terminates process group with bounded escalation. Worker restart marks interrupted work failed; VPS reconciles before new attempt. Reference review/export is a fresh attempt.
- Completed status contains result and canonical result_sha256. GET /api/jobs/{attempt_id}/output/{name}?offset=N&length=N returns bytes and X-Chunk-SHA256. VPS verifies full file size/digest. Only after verified receipt POST /purge with {"confirmation":"<result_sha256>"} deletes staged files; failed/cancelled attempts require "discard-failed". Tombstones retained during allocation. Scan result is in manifest.
- Staging cap 24 GiB / 64 attempt records; 20 GiB max individual source. Output storage and retention acceptance still required. Concurrency 1 enforced. 6h ceiling. Single replica. Worker storage ephemeral on Salad reallocation. VPS retains original verified files and results. Do not recycle with undelivered outputs.
- Actual model bytes and redistribution rights, secure build supply, private registry token, optional analyzer reference/profile input, Web dispatcher and lifecycle, external GPU acceptance remain pending. No model-inclusive image build until approval and tests.
